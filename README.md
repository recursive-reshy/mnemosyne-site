# mnemosyne-site

Static pages for **Mnemosyne**, a personal, self-hosted app that turns videos, articles, RSS feeds and newsletters into summarized notes in an Obsidian vault, and collects freelance job alerts for later analysis.

This repo only exists so Mnemosyne's Google OAuth consent screen has a public homepage and privacy policy. The app itself runs locally and isn't offered to the public.

- [Privacy policy](https://<username>.github.io/mnemosyne-site/privacy.html)

## Don't
- Rename the repo, move the pages or make the repo private. These URLs are registered on the Google Auth Platform **Branding** page, so update them there first if they ever change.
